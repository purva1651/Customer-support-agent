# Booking cancellation

For this demo booking CRM, cancelling a confirmed booking applies a cancellation fee equal to 10% of
the booking amount. The remaining 90% is returned as the calculated refund amount. A cancellation is
a risky action and the customer must approve it before the agent executes it. The CRM reports a
conflict if a booking has already been cancelled. This demo does not define cancellation deadlines
or a separate eligibility window.
